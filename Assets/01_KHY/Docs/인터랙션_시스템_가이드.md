# 약초의 신 — 인터랙션 시스템 가이드

---

## 한 줄 요약

> **타임라인 재생 → Signal에서 멈춤 → 플레이어가 Grip Hold로 링 충전 → 인터랙션 발동 → 타임라인 이어서 재생**

## 스크립트 역할 (누가 뭘 하는지)

### 입력 담당

| 스크립트 | 역할 | 비유 |
|---------|------|------|
| **VRInputManager** | Grip 버튼 눌렀는지 감지 | "손가락 감시자" |
| | 왼손/오른손 중 하나만 Active | 먼저 누른 쪽이 이김 |
| | 누르는 동안 진동 피드백 | 누를수록 세게 울림 |

### 충전 담당

| 스크립트 | 역할 | 비유 |
|---------|------|------|
| **RingChargeSystem** | Grip Hold 시간 → 게이지 0~100% 변환 | "타이머" |
| | Ray가 가리키는 대상 확인 | "조준경" |
| | 100% 되면 대상의 Execute() 호출 | "발사 버튼" |

### 인터랙션 대상 담당

| 스크립트 | 역할 | 비유 |
|---------|------|------|
| **RingInteractable** (베이스) | 모든 인터랙션 오브젝트의 부모 | "설계도" |
| **RockInteractable** | 바위 파괴 | 설계도로 만든 "바위" |
| **TreeGrowthInteractable** | 감나무 성장 | 설계도로 만든 "나무" |
| ... 기타 7종 | 각 씬별 인터랙션 | 같은 설계도, 다른 동작 |

### 타임라인 연결 담당

| 스크립트 | 역할 | 비유 |
|---------|------|------|
| **InteractionSignal** | 타임라인에 찍는 마커 | "여기서 멈춰!" 표지판 |
| **InteractionSignalHandler** | 멈추고 → 기다리고 → 재개 | "교통 경찰" |

## 스크립트 간 연결 관계

```
VRInputManager (입력 감지)
    │
    │  이벤트: OnGripStarted / OnGripHeld / OnGripReleased
    │
    ▼
RingChargeSystem (충전 관리)
    │
    │  Ray로 대상 탐색 → RingInteractable 찾음
    │  충전 100% → target.Execute() 호출
    │
    ▼
RingInteractable (대상 오브젝트)
    │
    │  Execute() → 시각적 효과 실행
    │  NotifyInteractionDone() → 완료 알림
    │
    ▼
InteractionSignalHandler (타임라인 제어)
    │
    │  OnInteractionDone 이벤트 수신
    │  → 타임라인 speed = 1 (재개)
    │
    ▼
타임라인 이어서 재생
```

## 각 스크립트 상세 설명

### 1. VRInputManager

**위치**: `Scripts_khy/Input/VRInputManager.cs`

**하는 일**: VR 컨트롤러의 Grip 버튼 입력을 관리

**핵심 규칙**:
- 왼손과 오른손 중 **먼저 누른 쪽만** Active
- 한쪽을 누르고 있으면 **다른 쪽은 무시됨**
- 누르는 동안 **진동이 점점 강해짐**
- 놓으면 Active 해제 → 다시 양쪽 사용 가능

**이벤트 3개** (다른 스크립트가 구독):
```
OnGripStarted(HandSide)      → "Grip 누르기 시작했어!"
OnGripHeld(HandSide, float)  → "계속 누르고 있어! 값은 0.7이야"
OnGripReleased(HandSide)     → "놓았어!"
```

**Inspector 설정**:
- Left/Right Grip Action → XR Input Action의 Grip 버튼
- Haptic 설정 → 진동 강도/커브

---

### 2. RingChargeSystem

**위치**: `Scripts_khy/Input/RingChargeSystem.cs`

**하는 일**: Grip 입력을 받아서 게이지를 충전하고, 100%가 되면 인터랙션 발동

**핵심 로직**:
```
Grip 시작됨
  → Ray가 가리키는 곳에 RingInteractable이 있는지 확인
  → 있으면: 충전 시작
  → 없으면: 아무것도 안 함

Grip 유지 중
  → 시간 경과에 따라 chargeProgress 증가 (0 → 1)
  → Ray가 대상에서 벗어나면 충전 취소

chargeProgress = 1 (100%)
  → target.Execute() 호출 → 인터랙션 발동!

Grip 놓음
  → 100% 미달이면 충전 취소, 게이지 초기화
```

**Inspector 설정**:
- Input Manager → VRInputManager 연결
- Left/Right Ray Interactor → XR Origin의 Ray Interactor 연결
- Charge Duration → 충전에 걸리는 시간 (기본 2초)

### 4. RingInteractable (베이스 클래스)

**위치**: `Scripts_khy/Interaction/RingInteractable.cs`

**하는 일**: 모든 인터랙션 오브젝트의 공통 기능을 정의

**필수 조건**: 오브젝트에 **Collider**가 있어야 함 (Ray가 맞으려면)

**생명주기**:
```
[평상시]
  오브젝트가 씬에 존재, 아무 일 없음

[충전 시작] → OnChargeBegin()
  아웃라인 활성화

[충전 중] → OnChargeUpdate(progress)
  아웃라인 두께 변화 (progress에 비례)

[충전 취소] → OnChargeCancelled()
  아웃라인 비활성화, 원래 상태로

[충전 100%] → Execute()
  인터랙션 실행!
  autoCompleteOnExecute = true면 → 즉시 완료 처리
  autoCompleteOnExecute = false면 → 하위 클래스가 VFX 끝난 후 직접 완료 처리

[완료] → NotifyInteractionDone()
  isCompleted = true → 더 이상 충전 불가
  OnInteractionDone 이벤트 → SignalHandler가 타임라인 재개
```

**Inspector 설정**:
- Ring Type → 링 색상 (Orange, Blue 등)
- Outline → QuickOutline 컴포넌트 (선택)
- Auto Complete On Execute → 체크: 베이스 클래스 직접 사용 시 / 해제: 하위 클래스 사용 시
- onExecute → UnityEvent (코드 없이 Inspector에서 연결 가능)

### 5. 씬별 인터랙션 (하위 클래스들)

**위치**: `Scripts_khy/Interaction/Scenes/`

모두 RingInteractable을 상속하며, `Execute()`를 오버라이드합니다.

| 클래스 | 씬 | Execute() 동작 |
|--------|-----|----------------|
| LanternInteractable | Sc01 | Light 점진적 밝히기 + 파티클 |
| RockInteractable | Sc03 | 원본 숨김 → 파편 활성화 + 폭발력 |
| TreeGrowthInteractable | Sc04 | BlendShape 또는 Scale 성장 + 열매 |
| WaterSwirlInteractable | Sc05 | 소용돌이 파티클 + 셰이더 |
| GrassFieldInteractable | Sc06 | 기존 GrassGroupManager.GrowAll() |
| CloudInteractable | Sc07 | 구름 Alpha 감소 + 비 파티클 + 빛 |
| HawkInteractable | Sc07 | 매 포물선 비행 + 열매 전달 |
| CauldronInteractable | Sc08 | 아궁이 불 + 실패 연출 |
| HeartEnergyInteractable | Sc09 | 에너지 포물선 이동 + 폭발 VFX |

**공통 패턴**:
```csharp
public override void Execute()
{
    base.Execute();                    // 베이스 처리 (로그, 아웃라인 끄기)
    StartCoroutine(MyEffectCoroutine()); // 코루틴으로 VFX 실행
}

private IEnumerator MyEffectCoroutine()
{
    // ... 시각적 효과 ...
    yield return new WaitForSeconds(duration);
    NotifyInteractionDone();           // ← 반드시 호출! 이게 있어야 타임라인 재개
}
```

### 7. InteractionSignalHandler

**위치**: `Scripts_khy/Signal/InteractionSignalHandler.cs`

**하는 일**: Signal을 받으면 타임라인을 멈추고, 인터랙션 완료를 기다렸다가 재개

**핵심 로직**:
```
Signal 도착 → HandleInteractionSignal()
  │
  ├→ playableGraph.SetSpeed(0)     타임라인 멈춤
  ├→ ringChargeSystem 활성화       충전 가능하게
  │
  │   ... 플레이어가 인터랙션 수행 ...
  │
  ├→ OnInteractionDone 이벤트 수신  인터랙션 완료됨
  ├→ 0.5초 대기                     시각적 여유
  └→ playableGraph.SetSpeed(1)     타임라인 재개
```

**Inspector 설정**:
- Director → 이 스테이지의 PlayableDirector
- Target Interactable → 기다릴 인터랙션 오브젝트 (RingInteractable)
- Ring Charge System → 씬의 RingChargeSystem
- Resume Delay → 완료 후 재개까지 대기 시간

## 타임라인 설정 방법

### 1. Signal Track 추가
```
타임라인 창 → 좌측 + 버튼 → Signal Track
```

### 2. Signal Emitter 배치
```
Signal Track 위에서 인터랙션 시점에 우클릭 → Add Signal Emitter
→ Inspector에서 Signal Asset = InteractionSignal (만들어둔 것)
```

### 3. SignalReceiver 연결
```
Stage 오브젝트의 SignalReceiver 컴포넌트에서:
  InteractionSignal → InteractionSignalHandler.HandleInteractionSignal
```

### 4. 완성된 타임라인 예시
```
[Signal Track]  ─────────── 🔔 ──────────────────────
[VO Track]      "바위를 부숴볼까요" ──── "대단해요!"
[Anim Track]    아이 걷기 → 멈춤 ──── 아이 기뻐함
[VFX Track]     ────── 반짝임 ON ──── 파괴 이펙트

                         ↑                ↑
                    여기서 멈춤      여기서부터 재개
```

## 새 인터랙션 추가하는 법

### 간단한 방법 (코드 없이)

1. 오브젝트에 `RingInteractable` 컴포넌트 추가
2. Ring Type 선택
3. Collider 확인
4. Auto Complete On Execute = 체크
5. onExecute UnityEvent에 원하는 동작 연결

### 커스텀 방법 (코드로)

```csharp
public class MyInteractable : RingInteractable
{
    public override void Execute()
    {
        base.Execute();
        StartCoroutine(MyEffect());
    }

    private IEnumerator MyEffect()
    {
        // 여기에 VFX, 애니메이션 등
        yield return new WaitForSeconds(1f);
        NotifyInteractionDone();  // ← 필수!
    }
}
```

## 자주 하는 실수

| 실수 | 증상 | 해결 |
|------|------|------|
| Collider 안 붙임 | Ray가 안 맞음, 충전 시작 안 됨 | Collider 추가 |
| NotifyInteractionDone() 안 호출 | 타임라인이 영원히 멈춤 | 하위 클래스에서 반드시 호출 |
| RingChargeSystem에 Ray Interactor 안 연결 | 충전 시작 안 됨 | Inspector에서 연결 |
| SignalReceiver에 메서드 안 연결 | Signal이 와도 아무 반응 없음 | HandleInteractionSignal 연결 |
| autoCompleteOnExecute = false인데 하위 클래스 아님 | 타임라인 멈춤 | true로 변경 |
