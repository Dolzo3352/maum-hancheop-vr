## 아키텍처 결정사항 (현 세션)

### 인터랙션 처리: Signal 방식
- Timeline Signal Emitter → SignalReceiver → InteractionSignalHandler
- Signal 도달 → director.Pause() → 인터랙션 대기 → 완료 시 director.Resume()
- Signal 에셋 1개 재사용, 받는 쪽에서 대상 오브젝트 지정

### 아이 NPC 이동: 키값 애니메이션
- Timeline Animation Track에서 부모 오브젝트에 위치 키값
- 인터랙션 후 반응 동작만 스크립트 이동 (MoveTowards/DOTween)
- NavMesh 사용하지 않음 (디오라마 소규모 무대)

### 입력 구조: 양손 배타적 Grip
- 왼손/오른손 Grip 동시 사용 불가 (먼저 누른 쪽 Active)
- Grip Hold → 시간 기반 게이지 충전 → 100%에서 발동
- 햅틱 진동: 진행도에 비례하여 강해짐

## 전체 시스템 연결도

```
[Timeline 재생]
    │
    VO Track + Anim Track 재생
    │
    🔔 InteractionSignal (Signal Emitter)
    │
    ▼
InteractionSignalHandler (SignalReceiver에서 호출)
    │
    ├→ director.Pause()
    ├→ RingChargeSystem.IsEnabled = true
    │
    │   [대기 상태]
    │   VRInputManager: Grip Hold 감지
    │       ↓
    │   RingChargeSystem: 게이지 충전 0→100%
    │       ↓ (Ray → RingInteractable 감지)
    │   RingChargeUI: 슬라이더 표시
    │       ↓
    │   100% 도달 → RingInteractable.Execute()
    │       ↓
    │   씬별 인터랙션 실행 (VFX, 애니메이션)
    │       ↓
    │   NotifyInteractionDone()
    │
    ├→ OnInteractionDone 이벤트 수신
    ├→ director.Resume()
    │
    ▼
[Timeline 재개]
    VO Track + Anim Track 계속
```

## 각 스테이지 타임라인 설정 방법

```
Stage_XX (GameObject)
├── PlayableDirector (타임라인)
│   ├── Signal Track
│   │   └── InteractionSignal (마커)  ← Signal Emitter
│   ├── VO Track
│   ├── Animation Track (아이 키값)
│   └── Activation Track (VFX)
│
├── SignalReceiver (컴포넌트)
│   └── InteractionSignal → InteractionSignalHandler.HandleInteractionSignal
│
├── InteractionSignalHandler (컴포넌트)
│   ├── director → (위의 PlayableDirector)
│   ├── targetInteractable → (해당 RingInteractable)
│   └── ringChargeSystem → (씬 전체 공유)
│
├── [인터랙션 오브젝트] (예: Rock)
│   ├── RockInteractable (RingInteractable 상속)
│   ├── Collider (Raycast용)
│   └── Outline (QuickOutline)
│
├── Spot Light
└── Volume
```

## 주의사항

- **모든 입력은 Grip Button Hold** — Trigger 아님 (기획서 v1.1 변경사항)
- **XR Ray Interactor 사용** — Physics.Raycast 직접 X, XRIT 내장 Ray Interactor 사용
- **RingInteractable에 Collider 필수** — Ray Interactor가 감지하려면 Collider 있어야 함
- **NotifyInteractionDone() 호출 필수** — 하위 클래스에서 VFX 완료 후 반드시 호출해야 Signal 재개됨
- **Signal 에셋 1개 재사용** — InteractionSignal.asset 하나만 만들고, SignalReceiver에서 각각 다른 Handler 메서드 연결
- **에디터 테스트**: RingInteractable의 ContextMenu "테스트: 인터랙션 실행"으로 개별 테스트 가능
