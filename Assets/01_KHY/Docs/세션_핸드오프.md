## 핵심 아키텍처 결정사항

### 1. Per-stage PlayableDirector
- 각 스테이지 GameObject 안에 PlayableDirector가 있음
- 타임라인 + 바인딩은 해당 Director의 Inspector에서 직접 설정
- NarrativeSequencer가 `GetComponentInChildren<PlayableDirector>()`로 자동 탐색
- StageData에서 timeline 필드 제거됨

### 2. 단일 타임라인 + Track Group
- 스테이지별 1개 타임라인에 Track Group으로 정리 (캐릭터, NPC, 연출, 오디오, 오브젝트)
- master+sub-timeline 방식 대신 선택 (타이밍 동기화 용이, 파일 수 감소)

### 3. The Line VR 스타일 전환
```
① 다음 스테이지 추가 활성화 (ActivateStageAdditive)
② 라이팅 크로스페이드 (Light intensity + Volume weight 동시)
③ 페이드 아웃 (짧은 암전)
④ 이전 스테이지 비활성화 (DeactivateStage)
⑤ 텔레포트 (WaypointTeleporter.TeleportImmediate)
⑥ 타임라인 재생
⑦ 페이드 인
```

### 4. 라이팅 설정
- 글로벌 앰비언트 = 거의 검정
- Environment Reflections = 0 (반사 제거)
- Directional Light 삭제
- 각 스테이지에 Spot Light (로컬) + Volume (포스트프로세싱)
- Spot Light: Outer Angle 120~140°, Intensity 씬 보면서 조절 (30 정도도 OK)

### 5. 텔레포트
- Timeline Signal 대신 NarrativeSequencer 전환 흐름 내에서 직접 호출
- WaypointTeleporter.waypoints[] 인덱스 = StageData.stageIndex 일치해야 함

## 주의사항

- **메인 프로젝트와 worktree 둘 다 수정해야 함** — Unity는 메인 경로(`Z:\Unity\Dear_Brave\`)를 읽음
- **StageData에 timeline 필드 없음** — 타임라인은 각 스테이지 PlayableDirector Inspector에서 직접 설정
- **lightingController가 null이면** 크로스페이드 건너뛰고 기존 하드컷 방식으로 동작 (하위호환)
- **waypointTeleporter가 null이면** 텔레포트 건너뜀
- **Volume은 Mode: Global, Priority 동일하게** — 크로스페이드 중 URP가 weight 기반 블렌딩
- **XR Simple Interactable** 사용 — 오브젝트 이동 없이 그랩 버튼으로 이벤트 발생
